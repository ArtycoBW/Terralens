# Презентация TerraLens

[TerraLens-defense.pptx](TerraLens-defense.pptx) — 15 слайдов 16:9. Основной рассказ занимает слайды 1–12, дополнительные таблицы и ограничения — 13–15. [Сценарий выступления и демонстрации](../../docs/DEFENSE_GUIDE.md).

Текст, архитектура, пять таблиц и три диаграммы редактируются в PowerPoint. Данные диаграмм включены в файл как встроенные Excel-таблицы; значения для отображения округлены до восьми знаков. Источники и пояснения указаны в заметках докладчика. Полные JSON и CSV доступны в [отчёте по реальным полям](../../docs/analysis/field-cases/REPORT.md).

Все 15 слайдов отрисованы после повторного импорта финального PPTX и просмотрены по отдельности. Проверены структура пакета, размеры, размещение, шрифты, таблицы и встроенные данные диаграмм. Открытие в настольном Microsoft PowerPoint не выполнялось; перед выступлением проверьте показ на компьютере площадки.

Архитектура представлена также отдельной [схемой и описанием](../../docs/ARCHITECTURE.md). Для демонстрации при отказе внешних сервисов используйте сохранённые графики и воспроизведение JSON без сети, явно обозначив их как записанные результаты.
