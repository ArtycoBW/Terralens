# Источники и атрибуция

## Данные

Карта использует OpenStreetMap: © OpenStreetMap contributors, ODbL; атрибуция остаётся видимой в интерфейсе. Поиск — Nominatim, контуры — Overpass. Эти контуры отражают доступное содержимое OSM и не являются кадастровым реестром.

Sentinel-2 C1 L2A поступает через Earth Search; Landsat 8/9 Collection 2 Level 2 — через Planetary Computer. Погода — Open-Meteo ERA5-Seamless. Даты получения, QA, версии источников и ограничения входят в snapshots и provenance результатов. [Обработка источников](ARCHITECTURE.md#источники-и-вычислительная-граница).

## Визуальные материалы

| Материал | Происхождение и использование |
|---|---|
| Земля, облака, освещение | Предоставленный шаблон Ascend / GetLayers; оригинал в `frontend/references/ascend` сохранён без изменений, адаптация в коде приложения |
| Colonnade | GetLayers, секция с раскрывающимися колонками |
| Carousel Spotlight | GetLayers, вращающаяся галерея форматов результата |
| Рельеф | Процедурная Three.js геометрия с OrbitControls и интерактивными метками; демонстрационная иллюстрация |
| AnimatedBeam | Предоставленный React-компонент 21st.dev, адаптация схемы процесса |
| Footer и sidebar | Предоставленные React-референсы CinematicFooter и Sidebar (21st/Aceternity), адаптация к TerraLens |
| Изображения полей, спутника, сезона и погоды | Сгенерированные маркетинговые иллюстрации; не измерения и не спутниковые снимки анализируемого поля |
| Постеры Земли и рельефа | Кадры соответствующих локальных 3D-сцен для статического отображения |

Отдельный LICENSE в предоставленном архиве Ascend отсутствует; права на этот исходник определяются условиями доступа к GetLayers. Этот репозиторий не объявляет сторонние материалы собственной разработкой и не выдаёт им новую лицензию.

## Шрифты и библиотеки

Golos Text Variable и JetBrains Mono подключены локально, лицензии OFL включены. Иконки — Tabler; интерфейсные примитивы — shadcn/Radix. Three.js и Draco сопровождаются лицензиями. Файлы лицензий находятся в [frontend/public/licenses](../frontend/public/licenses/); лицензия MapLibre копируется вместе с worker из установленного пакета во время сборки.

Зависимости и версии доступны в `frontend/package.json`, `frontend/pnpm-lock.yaml`, `uv.lock`, `requirements.lock`. Исходные материалы хакатона и предоставленные наборы данных сохраняют исходное происхождение; отдельная лицензия на них не придумывается.
