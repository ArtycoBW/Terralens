# Культура и динамика сенсоров: протокол до расчётов

Baseline: опубликованный ансамбль `50efa0dd0ff8d2d7`, commit `74d458e`.
Ровно четыре варианта в `ml/configs/crop-dynamics.yaml`: current, crop,
dynamics, combined. У всех три равновесных члена с seeds 42/107/211,
400 деревьев глубины 5, learning_rate 0.04, L2=10, пять циклов масок
с полным покрытием целей и прежними block masks. Гиперпараметры,
веса ансамбля и длины окон после просмотра метрик не меняются.

## Новые признаки

- crop: строковая культура как categorical feature CatBoost; null становится
  `<unknown>`. Взаимодействия с существующими sin/cos календарного дня
  обучаются деревьями. Категориальные статистики строятся только на train
  AOI каждого fold. ID поля и готовая климатология не используются.
- dynamics: для S2/Landsat/MODIS NDVI ближайшие строго предыдущее/следующее
  значения, расстояния до них в календарных днях, наклон между ними;
  медиана primary−sensor на совместных видимых датах в окне ±60 дней,
  число таких дат, интерполированное значение сенсора плюс эта медиана.
  Для медианы нужны ≥3 пары; иначе NaN. Прежний предел 14 дней для
  интерполированного сенсора сохраняется. Все признаки ограничены одним
  полем/сезоном/непрерывным сегментом культуры и пересчитываются после маски.
- combined: оба набора. Итого ожидается 54/55/78/79 признаков.

Для categorical JSON export передаётся train Pool, как требует
[CatBoost](https://catboost.ai/docs/en/concepts/python-reference_catboostranker_save_model#pool).
Новый формат v3 явно отделяет новые признаки от runtime старых артефактов.
Совместимость чтения числовых моделей v1/v2 сохраняется.

## Сравнение и публикация

Сохраняются 21 selection AOI до 2024 года, 5 GroupKFold по полям,
validation mask seeds 42/137 и прежняя доля 0.15. Старые восемь holdout AOI
полностью исключены. Calibration (5 AOI), assessment (5 AOI) и temporal
2024 не используются для выбора; эти данные уже просматривались и
считаются повторной диагностикой, не новым слепым holdout.

Выбор: минимальный pooled development point RMSE при block RMSE не выше
current. Условия обновления опубликованной модели: снижение point RMSE
минимум на 1%, отсутствие ухудшения block RMSE, выигрыш point RMSE минимум
в 4 из 5 folds и положительная нижняя граница 95% парного bootstrap
выигрыша по AOI (3000 повторов, seed 42). Учитываются все исходные y_true.
Показываются N, RMSE/MAE/bias/p95, срезы по gap/crop/sensor и bootstrap;
bootstrap не устраняет смещение от выбора лучшего из четырёх вариантов.

Сначала development-only. Если условия не выполнены, финальный артефакт
и submission сохраняются. Если выполнены, один final fit выбранного
варианта на прежнем selection, калибровка ансамбля и один проход повторной
assessment/temporal. После этого параметры не меняются. Обязательны
mask invariance, изоляция поля/сезона/культуры, неизвестная категория,
JSON roundtrip, совпадение baseline с предыдущим экспериментом,
полные тесты backend/ML и автономный submission без сети.

Новые независимые поля в этом эксперименте не получены. Официальные
ответы test недоступны; подтверждённый test RMSE не заявляется.
