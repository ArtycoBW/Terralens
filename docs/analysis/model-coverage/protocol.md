# Протокол следующего улучшения

До расчёта новых моделей зафиксированы восемь кандидатов mask-coverage.yaml,
прежние 21 selection AOI до 2024, GroupKFold=5 и validation masks 42/137.
Выбор только по development: минимум pooled point RMSE среди вариантов,
чья block RMSE не выше current. Calibration, assessment, temporal не читать
до фиксации всего выбора. Эти выборки уже знакомы и не являются слепыми.

После выбора одного базового варианта допускается один дополнительный
эксперимент: равновесный ансамбль той же конфигурации с seeds 42/107/211,
без поиска весов. Выбирать его только при снижении point RMSE и отсутствии
роста block RMSE относительно выбранной одиночной модели.

Условие публикации: point RMSE ниже current минимум на 1%, block RMSE
не выше current, point RMSE лучше минимум в 4 из 5 folds; парный bootstrap
3000 повторов по AOI (seed 42), нижняя граница 95% выигрыша point RMSE>0.
Срезы/AOI и p95 должны быть представлены, selection optimism оговорён.
Если условия не выполнены, текущий finalartifact не заменять и не пушить.

После фиксации победителя один полный прогон с калибровкой и повторной
диагностикой. Исходные target/маски validation не менять; все динамические
поля скрытой строки удалять до пересчёта признаков. Никаких новых параметров
по результатам assessment/temporal, никакого refit на этих AOI.
