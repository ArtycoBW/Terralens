# Покрытие обучающих целей и качество сенсорного контекста

Проверен следующий этап улучшения после модели `e156fcdadef59ed0`. Выбор
параметров выполняется только на development: прежние 21 AOI до 2024 года,
пять GroupKFold по полям, validation masks 42/137. Старые восемь holdout AOI
исключены; calibration/assessment/temporal не участвуют в подборе. Эти
проверочные данные уже просматривались и не являются новым слепым holdout.

## Гипотезы и условия принятия

[Протокол](protocol.md) зафиксирован до новых расчётов. В первом этапе
сравниваются восемь одиночных конфигураций. Выбор — минимум pooled point
RMSE при block RMSE не выше текущей модели. После выбора одного варианта
проверяется один равновесный ансамбль той же конфигурации с seeds 42/107/211.
Новых весов и порогов не подбирается. Ансамбль принимается только при
снижении point RMSE без роста block RMSE относительно одиночной модели.

Для публикации нужны минимум 1% выигрыша point RMSE относительно текущей
модели, отсутствие роста block RMSE, улучшение point RMSE минимум в 4/5 folds
и положительная нижняя граница 95% парного AOI-bootstrap интервала выигрыша.
Bootstrap использует 3000 повторов, seed 42, с пересэмплированием целых AOI.
Параметры не меняются после повторной assessment.

## Разбор крупных ошибок

45 худших development point примеров (около 1%) дают 19,70% суммы квадратов
ошибок текущей модели. У 41 из 45 (91,11%) цель выходит за диапазон ближайших
доступных соседей более чем на 0,05 NDVI; среди всех 4482 примеров доля 24,54%.
Эти 45 примеров принадлежат 17 полям. Медианное расхождение между самими
соседями у них не выше общего:0,0561 против 0,0580.

Это не доказывает ошибку спутника: возможны и краткий реальный переход, и
шум наблюдения. Одних соседних primary значений часто недостаточно, чтобы
восстановить такую цель. Исходные y_true сохраняются во всех метриках.
Raw сенсор скрытой строки используется только для разбора ошибок, не как
обучающий признак. [Сводка](error_analysis.json), [45 примеров](worst_points.csv).

В выбранных кандидатах проверяются новые признаки, доступные из замаскированного
контекста: расстояние до ближайшего значения каждого сенсора, интервал между
его опорными наблюдениями, число доступных NDVI-сенсоров, разброс и стандартное
отклонение их интерполированных оценок. Истинный сенсор скрытой даты не используется.
Для естественных пропусков и отсутствующих источников сохраняется NaN.

## Полное покрытие обучающих целей

В прежнем варианте 15918 обучающих примеров охватывали 10285 уникальных целей
из 14977 пригодных. Остальные цели использовались как контекст или для priors,
но не как метки для CatBoost. Шесть случайных повторов увеличивают охват до
13412 целей при 31663 примерах.

Новый режим один раз перемешивает известные цели каждого AOI/сезона и делит
их на пять частей. За пять point masks каждая цель скрывается ровно один раз.
Между ними сохраняются block masks длиной 8/15/30/45/65 календарных дней.
Получается 26265 примеров и полное покрытие всех 14977 целей для seed 42.
Priors каждого внутреннего примера пересчитываются после маскирования.
Validation masks остаются прежними. [Числа и hashes](training_coverage.json).

## Восемь одиночных вариантов

| Кандидат | Points RMSE, N4482 | Blocks RMSE, N4430 |
|---|---:|---:|
| current | 0.072445 | 0.101430 |
| random_6 | 0.071724 | 0.097469 |
| cover_5 | 0.071707 | 0.099614 |
| cover_quality | 0.070559 | 0.098060 |
| cover_depth5 | 0.070468 | 0.098515 |
| cover_depth6 | 0.069958 | 0.097282 |
| cover_quality_depth5 | **0.069591** | **0.096617** |
| cover_regularized | 0.070788 | 0.098755 |

У всех 400 деревьев; current использует прежние три повтора, random_6 — шесть,
остальные — пять повторов с полным покрытием. Quality включает новые признаки;
depth5/depth6 задают глубину вместо прежней 4. Regularized — depth5 и L2=20
вместо 10. [Конфигурации и split](selection_split.json), [метрики](selection_metrics.csv).

Выбран `cover_quality_depth5`. Он улучшил обе метрики во всех пяти folds:
points на 3,94%, blocks на 4,74%. 95% AOI-bootstrap интервал абсолютного выигрыша
RMSE: points 0,002079…0,003693; blocks 0,002904…0,006867.
[Парное сравнение и срезы](single_comparison.json).

Покрытие всех целей само по себе не оказалось универсально лучше случайных
повторов: у cover_5 немного лучше points, но хуже blocks, чем у random_6.
Наилучший результат получен совместно с качеством контекста и глубиной 5.
Bootstrap оценивает устойчивость на имеющихся AOI и не устраняет смещение от
выбора лучшего кандидата на той же development-выборке.

## Воспроизведение

```sh
uv run --frozen python -m terralens_ml research --config ml/configs/mask-coverage.yaml --development-only
uv run --frozen python -m terralens_ml research --config ml/configs/mask-ensemble.yaml
```

Второй запуск сначала сравнивает single/ensemble на development, фиксирует
победителя, затем выполняет fit на selection, калибровку и повторную диагностику.
Артефакт создаётся в `artifacts/mask-ensemble/model`; финальный артефакт в
репозитории обновляется только после проверки условий публикации и тестов.

## Ансамбль и решение о публикации

Равновесный ансамбль выбранной конфигурации с seeds 42/107/211 получил
point RMSE **0,069207** и block RMSE **0,095374**. Относительно одиночного
варианта дополнительное снижение составляет 0,55% / 1,29%. Парные 95%
интервалы абсолютного выигрыша: points 0,000092…0,000663; blocks
0,000211…0,002282. [Сравнение с одиночной моделью](ensemble_comparison.json).

Относительно модели начала этого этапа выигрыш составляет **4,47% / 5,97%**,
обе метрики улучшились во всех пяти folds. 95% AOI-bootstrap интервал
абсолютного выигрыша: points 0,002588…0,003945; blocks 0,003924…0,008293.
Все заранее заданные условия публикации выполнены.
[Решение](publication_decision.json), [срезы и folds](final_comparison.json).

Прогнозы одиночного варианта во втором этапе побайтно совпали по числовым
значениям с первым этапом. После выбора ансамбля параметры не менялись;
веса усреднения равны 1/3 и не оптимизировались. Final fit использует
прежние 21 selection AOI до 2024, 79 256 обучающих примеров и все 14 977
уникальных пригодных целей. У каждого члена 400 деревьев глубины 5,
L2=10 и 54 признака. Число примеров по каждому seed отражено в
[diagnostic_evidence.json](diagnostic_evidence.json).

Итоговая residual correction вычисляется средним трёх моделей, после чего
применяется единая калибровка ансамбля. Наблюдаемые значения сохраняются.
Артефакт `50efa0dd0ff8d2d7` опубликован в `ml/artifacts/final`. Он использует
schema_version=2: старый runtime отклоняет неизвестную версию вместо
случайного использования только первого члена ансамбля. Новый runtime
сохраняет поддержку прежних одиночных артефактов v1. Финальная правка
формата не меняла нативные веса CatBoost и численные результаты.

## Калибровка и повторная диагностика

Параметры зафиксированы до расчёта этих метрик. Источники данных уже
просматривались в предыдущих этапах, поэтому независимым слепым
подтверждением качества эти числа не являются.

| Scope | N | RMSE | Покрытие 90% интервала | Средняя ширина NDVI |
|---|---:|---:|---:|---:|
| assessment_points | 511 | 0.072679 | 91.19% | 0.213852 |
| assessment_blocks | 514 | 0.090523 | 92.22% | 0.322046 |
| temporal_points | 282 | 0.057872 | 95.04% | 0.211578 |
| temporal_blocks | 286 | 0.078942 | 94.76% | 0.320379 |

Калибровка использует 1 173 residual на пяти отдельных AOI, без refit на
них. Метод — эмпирические квантили абсолютной ошибки, группы
short/long/edge/prior и pooled fallback при N<100. Показатели calibration
не считаются независимым измерением; зависимость точек внутри поля и
domain shift не позволяют обещать безусловную гарантию покрытия.
[Все метрики](final_metrics.csv), [калибровка и provenance](diagnostic_evidence.json).
