# Протокол улучшения, зафиксированный до расчёта

Сохранить старые selection AOI, годы до 2024, пять пространственных folds
и две validation mask seeds. Сравнить шесть конфигураций improvement.yaml.
Выбирать минимум pooled development points RMSE при отсутствии ухудшения
development blocks относительно previous. Assessment, temporal и calibration
не читать до выбора. Эти выборки уже просмотрены в прошлой работе и далее
являются повторной диагностикой, а не слепым подтверждением качества.

Проверить парную разницу ошибок bootstrap по целым AOI с повторными масками
внутри AOI. Для дальнейшего смешивания с историей сначала зафиксировать
победителя признаков, затем использовать исключительно development OOF.
Не подбирать по official test (ответы отсутствуют).

После выбора один полный прогон для калибровки/повторной диагностики,
проверки leakage invariance, CLI/worker parity и автономного submission.
