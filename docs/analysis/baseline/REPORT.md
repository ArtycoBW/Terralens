# Первый baseline TerraLens

Расчёты выполнены на предоставленном train, исходный SHA-256: `08e4f724f616459c944050aa25c1a46d16055501c785faeda74edd907c665fc6`. Скрытые test labels недоступны. Все числа ниже — локальные, а не официальная оценка.

## Протокол

Из 39 полей восемь зафиксированы как holdout; 31 поле разделено на пять development folds. Глобальные priors обучаются только на training AOI соответствующего fold. На отложенном поле открыт соседний контекст, а контрольные динамические поля скрываются до расчёта. Seeds масок: 42 и 137. Для holdout/временной проверки — 991. Исходные y_true, включая выбросы, не изменяются.

Точечная маска скрывает около 15% известных целей каждого polygon/year. Блочная проверка скрывает календарные окна 8/15/30/45/65 дней. Межсезонная интерполяция запрещена, край ограничен 14 днями, расстояние между соседями — 60 днями. Эти пороги — исходные проектные настройки, а не результат тюнинга.

Точные значения, MAE, bias, p95 и срезы по AOI/crop/year/gap находятся в `metrics.csv` и `report.json`. N включает оценки разных фиксированных масок; эти точки не являются независимыми наблюдениями для доверительного интервала.

Выбор M0 сделан по pooled development RMSE точечной маски. Для крупных блоков M1 лучше; единого выигрыша на всех сценариях нет. Доля глобального резервного расчёта для development-точек около 0,47%, для development-блоков около 32,1%, для holdout-блоков около 43,3%. Длинные пропуски — явная слабость текущей модели.

Официальный test содержит 3 112 контрольных строк; 2 648 из них относятся к AOI, отсутствующим в train, и 925 — к 2025 году. Текущий submission использует только открытый test-context и обученные priors, без дополнительной train-истории. Он проверен на точные ключи, порядок, конечные числа и повторное чтение.

## Ограничения и следующие эксперименты

Проверены три метода. CatBoost, robust seasonal smoother, маршрутизация по длине gap, погодные признаки, sensor harmonization и калибровка ещё не исследованы. Представленные результаты не являются заявлением высокого конкурсного качества. Для новых экспериментов нужен отдельный журнал; уже просмотренный holdout не использовать как инструмент тюнинга.

Независимой разметки агрономических событий нет. Правила аномалий проверены на граничных примерах и синтетических эпизодах; precision/recall засухи не заявляются. Короткий live spike проверяет получение данных и происхождение значений, а не точность диагностики.

## Воспроизведение

`uv run --frozen python -m terralens_ml evaluate --config ml/configs/validation.yaml` создаёт полный набор масок и predictions.csv. В репозитории сохранены компактные результаты, split_manifest и обученный JSON-артефакт в `ml/artifacts/baseline`.

## Интеграционные доказательства

`api-smoke-local` и `api-smoke-docker` содержат запросы, реальные геометрии, job/run и ряд, полученные через HTTP и Celery. Период 01–10.06.2024: два наблюдаемых дня и восемь восстановленных. История не запрашивалась; zscore отсутствует и поле не объявляется здоровым. Первоначальное ложное scene_limit в этих runs сохранено как часть истории; код пагинации исправлен отдельно и проверен тестом.

`offline-evidence.json` подтверждает два одинаковых submission в отдельном окружении без Django и с запрещёнными сетевыми соединениями. `read-latency.json` фиксирует ограниченное локальное измерение обычного чтения API; это не доказательство работы под конкурентной нагрузкой.
