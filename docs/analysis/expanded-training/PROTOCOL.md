# Расширение обучения и ускорение: протокол до эксперимента

Baseline: `131aee618934151e`, commit `31f0d97fdd6d8be3c0cc25e837ee681877526faf`.
Пользователь разрешил применять новые CSV и допускает до +25% CPU inference.

`train_dataset.csv` после нормализации полностью совпадает с прежним train.
`test_features.csv`: 49 190 строк, 20 AOI, 2 323 контрольные строки; поля и
ключи не пересекаются с train. `private_test_ground_truth.csv` доступен по
прямому разрешению пользователя; до фиксации кандидата прочитаны только
заголовок и checksum, значения ответов не использованы.

Проверяется ровно одна гипотеза качества: расширить train при неизменных
78 features, трёх seeds 42/107/211, 400 деревьях глубины 5 и прежних масках.
Предыдущие пять calibration AOI остаются полностью исключёнными из fit.
Остальные 34 AOI и все предоставленные годы 2010–2024 разрешены для final
fit. Старые assessment/holdout уже были просмотрены и теперь явно становятся
обучающими данными; их старые метрики не оценивают новый final artifact.

Для development сохранить прежние пять validation folds, их 21 AOI,
годы до 2024, mask seeds 42/137, point fraction 0.15 и календарные blocks.
В каждом fold обучать expanded на всех разрешённых 34 AOI, кроме всех лет
validation AOI. Сравнить с сохранёнными OOF dynamics на точно тех же ключах,
truth и gap_days. SHA-256 baseline predictions фиксируется в плане;
при их отсутствии допускается воспроизведение baseline по старому протоколу.
Новые внешние test-метки не участвуют в этом этапе.

Условия принятия development: снижение pooled point RMSE ≥1%, без роста
block RMSE, point-выигрыш минимум в 4/5 folds, положительная нижняя граница
95% парного AOI-bootstrap (3000 повторов, seed42). Проверка на известных
development AOI не объявляется новой независимой валидацией.

При выполнении условий — один final fit на 34 AOI/2010–2024, новая calibration
на прежних пяти calibration AOI с mask seed991 и уровнем90%. Затем зафиксировать
hashes модели и baseline/candidate прогнозов нового test до чтения его ответов.
Один отдельный assessment новых 20 AOI: exact key matching, pooled RMSE/MAE,
bias/p95, AOI bootstrap и покрытие интервалов. Это локальная оценка по
предоставленному ground truth, не автоматически официальный результат платформы.
После assessment конфигурацию не менять; при ухудшении внешнего RMSE
кандидат не публиковать. Новые test-метки в обучение и calibration не включать.

Независимо переносится точный скоростной рефакторинг: интервалы массивами,
предварительно выделенные массивы features вместо многочисленных .loc.
Проверить точное совпадение всех результатов старого артефакта на обоих
test inputs, shuffle/nonstandard-index/mask/domain scenarios. Сравнить
legacy/current на одной машине, затем candidate/current в новом runtime;
число деревьев и schema features не меняются. Общий бюджет≤1.25 legacy baseline.
Не менять модель/параметры по наблюдаемому времени после private assessment.

Публикация включает артефакт, обе batch-выгрузки, provenance, документацию,
standalone offline проверки и backend/ML tests. Прежнюю модель сохранить
для воспроизведения и прошлых runs. Исходные новые CSV не переписывать.
