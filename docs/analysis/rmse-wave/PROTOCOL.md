# Маски, веса, межсенсорные пары и ёмкость CatBoost

Протокол фиксируется до обучения пяти кандидатов. Baseline — действующие
веса 131aee618934151e и ускоренный runtime. Новый предел времени считается
консервативно от уже ускоренного baseline: не больше 1,25 его времени.

Сохраняем прежние 21 selection AOI до 2024, пять outer spatial folds,
маски validation seeds 42/137, fraction 0,15, points и blocks. Все глобальные
параметры каждого fold обучаются только на его train AOI до 2024. Пять
calibration AOI отдельно. Состав train не расширяется. Старые assessment,
temporal и предоставленные private-ответы уже просмотрены; они не участвуют
в выборе и не называются новым слепым holdout. Private CSV не читается.

Пять отдельных вариантов относительно текущей конфигурации:

1. `equal_target_weight`: вес примера обратно пропорционален числу повторов
   исходной цели; веса нормированы к среднему 1, чтобы не менять масштаб L2.
2. `seven_point_parts`: семь покрывающих point-масок вместо пяти, около
   14,3% целей в каждой вместо 20%; каждая цель всё ещё скрыта ровно один раз.
   Пять block-масок остаются теми же для соответствующего seed.
3. `sensor_alignment`: шесть признаков независимых S2↔Landsat пар. Общий bias
   — медиана AOI-медиан по разрешённым train co-observations. Внутри сегмента
   поле/сезон/crop локальная медиана пар ±60 дней стягивается к общему bias:
   n/(n+8). Дополнительно count, nearest-pair age, MAD, две интерполированные
   оценки, приведённые в шкалу другого сенсора. Primary не определяет пары.
   Внутренние маски удаляют запрещённые сенсоры; общий bias пересчитывается
   после каждой маски. При отсутствии пар общий bias=0 с явным count=0.
4. `longer_boosting`: 800 depth5, learning_rate 0,025, прежняя L2=10.
5. `deeper_regularized`: 600 depth6, learning_rate 0,03, L2=20.

Ансамбли по три seeds 42/107/211, два CPU-потока. Погода, crop-category,
семь отвергнутых transition-признаков отключены. Точный feature cache может
повторно использовать одинаковые маски/матрицы между весами и настройками
деревьев; он не включает validation и проверяется по ключам/контрольным суммам.

До сравнения проверяется воспроизведение baseline fold 0 с новой реализацией
fit на тех же ключах/truth/gaps; допуск predictions 1e-12. Для всех кандидатов
пять folds, pooled RMSE, MAE, bias, p95, AOI/gap-срезы и парный AOI-bootstrap
3 000/seed42. Решение не принимается по одному удачному fold.

Условия допуска: снижение pooled points RMSE не меньше 1%, blocks не хуже
baseline, point RMSE лучше минимум в 4/5 folds, нижняя граница 95% парного
AOI-bootstrap выигрыша положительна. Эти условия не устраняют множественный
выбор на уже знакомом development: этот предел доказательности будет указан.

Если допущены минимум два независимых изменения, разрешена ровно одна
комбинация: объединить допущенные изменения масок/весов/калибровки с лучшим
допущенным набором параметров деревьев, если такой есть. Другие смеси и
донастройки после просмотра результатов запрещены в рамках этой волны.
Комбинация проходит те же пять folds и условия; итог — минимальный pooled
point RMSE среди допущенных вариантов, при точном равенстве — имя по алфавиту.

Только после выбора: final fit на прежних 21 AOI до 2024; отдельная калибровка
по прежним пяти calibration AOI, seed991, номинал90%. Измерить десять
чередующихся warm-повторов полного reconstruct на обоих test CSV. Не включать
imports/read/load/write/HTTP/БД в эти замеры. Сравнить с текущей ускоренной
моделью, сохранить latency samples и hashes. При превышении +25% не публиковать
и не переключаться на другой вариант по новым результатам.

Публикация требует также ML/backend tests, сохранения наблюдений, масок,
границ, shuffle, JSON roundtrip, standalone без сети, Docker parity и валидных
submission. Для нового test ground truth отсутствует. Старый private score
не пересчитывается и не служит дополнительным фильтром. При отсутствии
победителя веса остаются прежними, результаты отрицательных опытов сохраняются.
