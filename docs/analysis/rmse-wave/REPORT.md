# Снижение RMSE: пять экспериментов и новая рабочая модель

06.09.2026. Установлена модель **594d4e6509459b08**: ансамбль трёх CatBoost,
600 деревьев глубины 6, learning rate 0,03, L2=20. Число признаков осталось 78.
На тех же пяти development folds point RMSE снизился с **0,068260 до 0,067357**
(**1,32%**), block RMSE — с **0,094173 до 0,093206** (**1,03%**).
Point RMSE улучшился во всех пяти folds.

Полный warm-инференс замедлился на **4,0% / 7,0%** на двух CSV относительно
уже ускоренного baseline. Предел пользователя +25% выполнен. Новые веса,
калибровка и оба submission установлены; предыдущая версия сохранена.
Это подтверждённый development-выигрыш, не измерение нового test RMSE.

## Реализация гипотез

**Веса.** Каждый пример получает вес, обратный числу повторов исходной цели;
средний вес нормируется к 1 для сохранения масштаба L2. При этом у всех
исходных целей одинаковый суммарный вклад. Получился устойчивый компромисс:
points лучше, blocks хуже. Этот флаг не включён в рабочей модели.

**Маски.** Семь частей дают примерно 14,3% скрытых целей на point-маску вместо
20%, приближаясь к 15% validation/test. Каждая цель скрывается ровно один раз;
пять block-масок остаются идентичными прежним для соответствующего seed.
Простое сближение плотности масок не помогло. Рабочая модель сохраняет пять
point-частей и пять block-масок.

**Межсенсорные пары.** Шесть новых признаков: стянутая к общему уровню локальная
медиана S2−Landsat, count, давность ближайшей пары, MAD и две интерполированные
оценки в шкале другого сенсора. Общий bias — медиана AOI-медиан train;
локальный bias в окне ±60 дней имеет вес n/(n+8). Primary не определяет пары.
Расчёт изолирован по полю/сезону/отрезку культуры, запрещённые сенсорные
значения удаляются до признаков. Общий bias пересчитывается после внутренних
масок. Кандидат не улучшил основной RMSE; флаг в рабочей модели отключён.

**CatBoost.** Learning rate стал явным проверяемым параметром. Выбранные
600 depth6/LR=0,03/L2=20 используют те же 78 признаков и ансамбль seeds
42/107/211. Ранее использованный дополнительный набор PCHIP/transition
признаков не включён. Улучшение получено изменением параметров обучения и
ёмкости модели, без расширения входного контекста и состава train.

Подготовка обучающих матриц выделена в отдельную функцию. Исследовательский
cache хранит точные числовые столбцы, residuals и исходные индексы в NPZ без
pickle; ключ включает контекст, маску, параметры признаков и source hash.
Параметры деревьев и веса не меняют матрицу, поэтому она повторно используется
между соответствующими опытами. Проверяются контрольные суммы. Это ускоряет
исследование и не добавляет зависимостей к рабочему инференсу.

## Границы результата

Пять кандидатов выбраны и проверены на ранее использовавшемся development.
Bootstrap после такого выбора не заменяет независимый holdout и не устраняет
эффект множественных сравнений. Поэтому 1,32% — оценка выигрыша на этих
development folds; гарантировать тот же процент на новых полях нельзя.

`private_test_ground_truth.csv` в этой волне не читался. Он относится к
исходным 3 112 пропускам и уже был просмотрен раньше; его результат 0,075034
относился к **предыдущей** модели 131aee618934151e. Это не метрика новых весов.
Ответов для `test_features.csv` нет. Старые assessment/temporal оценки также
не пересчитывались и не участвовали в выборе.

## Воспроизведение

Из корня в Python workspace с установленными зависимостями из `uv.lock`:

```sh
.venv/bin/python scripts/train_rmse_wave.py --stage develop
.venv/bin/python scripts/train_rmse_wave.py --stage final
.venv/bin/python scripts/train_rmse_wave.py --stage benchmark
.venv/bin/python -m terralens_ml predict --input test_features.csv --model ml/artifacts/final/manifest.json --output artifacts/submission-reproduced.csv
.venv/bin/pytest -q
```

План защищён от изменения кода/данных/параметров при продолжении. `develop`
использует сохранённые fold-файлы и cache; повторные final fit и benchmark
в том же каталоге отклоняются. Для нового полного запуска нужны новые пути
output/evidence и копия протокола. Требуются прежние baseline OOF
`artifacts/crop-dynamics/predictions.csv` и модель
`artifacts/expanded-training/previous-model/manifest.json`; hashes указаны
в plan. OOF хранятся в игнорируемом `artifacts/rmse-wave`. После проверки
восстанавливаемый кеш матриц удалён при очистке каталога; промежуточные
прогнозы, маски и версии моделей сохранены.
