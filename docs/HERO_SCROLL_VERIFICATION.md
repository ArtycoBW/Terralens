# Проверка прокрутки первой секции

Дата: 05.09.2026. Проверена production-сборка Next.js в Docker на localhost:3001.

## Результат

Первая секция содержит один закреплённый экран на пути 500svh. Земля Ascend
меняет положение, масштаб и ракурс синхронно с тремя главами. Только после
завершения пути экран уходит вверх и открывает Colonnade. Обратная прокрутка
возвращает прежний ракурс. Навигация позволяет пропустить рассказ.

Исходная причина: прогресс рассчитывался по всему документу, хотя отрисовка
прекращалась уже после 1,25 высоты окна. Теперь прогресс относится только к hero,
а видимость canvas определяет необходимость отрисовки. Повторная настройка
reduced motion приостанавливает сцену без потери контекста.

## Найденная ошибка перехода к возможностям

В CI предыдущего коммита `801b9a6` не прошёл keyboard-тест Colonnade: после End
фокус оставался на «Контекст», но выбранная панель возвращалась к «Территория».
Причина — `pointerenter` при изменении геометрии колонок под неподвижным курсором.
Теперь hover-переключение требует фактического движения указателя. Тест паркует
курсор в колонке перед клавиатурным переключением и проверяет возврат к мыши.
Повторённый сценарий — 6 успешных проходов desktop/mobile; дополнительная проверка
наведения — успешно. Типы, lint и production build после исправления пройдены.
