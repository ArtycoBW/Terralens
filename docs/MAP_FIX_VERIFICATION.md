# Проверка рисования контура — 05.09.2026

Исправлены две причины сбоя:

- Панель подсказок над картой перехватывала события мыши и касания. Декоративные накладки теперь пропускают события к canvas; кнопки остаются интерактивными.
- В production Next.js отсутствовал рабочий URL ES-модуля MapLibre 6. Растровая подложка отображалась, а GeoJSON-слои оставались невидимыми. Скрипт перед `dev` и `build` копирует worker и его shared-модуль из установленной версии пакета; `setWorkerUrl` указывает на локальный файл. Оба файла и лицензия попадают в Docker image. См. [официальную инструкцию для Next.js](https://maplibre.org/maplibre-gl-js/docs/#installation).

Левая панель получила внутренние отступы 20 px, кнопка перехода к созданию — отступы 12 px и перенос длинной надписи. Вершины рисуемого контура обозначены контрастными точками.

В `frontend/tests/e2e/map-interaction.spec.ts` добавлены проверки кликов/касаний под подсказкой и реальных пикселей первой вершины. Обе регрессии воспроизведены до исправления. Проверка GeoJSON сама по себе не обнаруживала отсутствие отрисовки.

Логи, снимки карты и результат создания временного поля через реальный API сохраняются локально в `artifacts/map-fix`. Тестовые поля удаляются после проверки.

После исправления пройдены TypeScript, ESLint, production Docker build и 16 браузерных проверок на desktop/mobile: реальные пиксели вершины, замыкание мышью/касанием, восстановление черновика, редактор карты, sidebar, отсутствие горизонтального переполнения и Axe WCAG AA. Реальный API вернул 201 при сохранении нарисованного поля; удаление временного поля также проверено.
